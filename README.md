# 🎮 Aplicativo SaveGame
> **Transforme suas finanças em uma aventura épica.**

**SaveGame** é um aplicativo de gerenciamento financeiro para Android que usa elementos de **gamificação** para tornar o controle de seus gastos divertido e motivador. Em vez de apenas anotar números, você completa "missões", ganha XP e sobe de nível, mantendo sua saúde financeira em dia.

---

## ✨ Principais Recursos

### 💰 Gerenciamento de Missões (Transações)
* **Receitas e Despesas:** Registre suas transações com uma interface limpa e rápida.
* **Categorias Modernas:** Organização inteligente (alimentação, entretenimento, tecnologia, assinaturas, etc.).
* **Canais e Setores:** Identifique exatamente de onde vem e para onde vai seu dinheiro (por exemplo, Salário CLT, Despesas Fixas Pessoais).

### 🏆 Sistema de Níveis (Gamificação)
* **XP Progressivo:** Cada transação registrada concede experiência.
* **Níveis e Títulos:** Evolua de um "Iniciante" a uma "Lenda das Finanças".
* **Conquistas (Emblemas):** Desbloqueie emblemas exclusivos (Madeira, Ferro, Quartzo, Bronze, Prata, Ouro e Diamante).

### 📊 Interface e Filtros
* **Design Plano Moderno:** Cartões elegantes que se expandem com animações fluidas para revelar detalhes.
* **Filtros Inteligentes:** Pesquise por texto ou filtre por período (1 mês, 3 meses), tipo ou setor.
* **Modo Escuro Nativo:** Adapta-se automaticamente à aparência do seu sistema.

---

## 🛠️ Tecnologias Utilizadas

Criado com as melhores práticas modernas de desenvolvimento Android:

* **Kotlin**: Linguagem principal.
* **Jetpack Compose**: Interface de usuário declarativa moderna.
* **Banco de Dados Room**: Persistência de dados local segura e eficiente.
* **MVVM (Model-View-ViewModel)**: Arquitetura limpa e escalável.
* **Coroutines e Flow do Kotlin**: Processamento de dados assíncrono em tempo real.
* **Material 3**: O mais recente padrão de design do Google.
